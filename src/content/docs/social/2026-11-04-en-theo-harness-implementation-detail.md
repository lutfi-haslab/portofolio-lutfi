Theo Browne, creator of T3 Code, has a thesis every coding-agent user should hear: the harness layer — the tools and syntax that let a model act — is collapsing into a mere implementation detail.

The number he offers is simple. The performance gap between Claude Code and Codex, when both run Codex models, is just 3 to 5 percent. Any wider than that, he says, is a failure in the model layer, not the harness.

That fits my long-standing yardstick: be loyal to results, not to tools. If harnesses become a commodity, the decision moves to the two things that can actually be measured: model capability and price per finished task.
