Ini contoh favoritku minggu ini soal kenapa klaim harus dibedah, bahkan klaim dari orang yang kupercaya seperti Theo.

Theo memposting bahwa selama dua minggu, lebih dari 60% pengguna T3 Code yang memakai Codex juga memakai Claude Code — dan menjualnya sebagai bukti bahwa harness adalah produknya. Kedengarannya meyakinkan, sampai seorang developer menarik data dari status page resmi kedua perusahaan untuk jendela yang sama.

Hasilnya: dalam dua minggu itu Codex berada di bawah insiden terbuka selama 42,7 jam, sementara Claude Code cuma 34 menit. Orang pindah ke Claude Code bukan karena jatuh cinta pada harness-nya; mereka pindah karena Codex sedang down.

Pelajaran lamaku berlaku lagi: statistik dari pemilik produk tentang kenapa kamu butuh produknya selalu perlu dicek ke sumber independen. Bukan berarti Theo bohong — datanya benar, cuma ceritanya beda.
